# Start here: daily operator guide

**Audience:** authorized administrators and read-only operators using the
browser application.

**Environment:** Revolut Sandbox only. No live money or live customer data.

## Before each session

1. Open the private application address supplied by your administrator.
2. Confirm the yellow banner says **REVOLUT SANDBOX · NO LIVE DATA**.
3. Sign in with your own username and password.
4. Enter the current six-digit authenticator code when requested.
5. Check **Operations**. Continue only when it says **Clear**.
6. Check **Backup**. Do not authorize execution unless it says **Fresh**.
7. Select **Operator guide ↗** to open the side-by-side reference.

Stop and contact the administrator if the Sandbox banner is missing, Operations
is Blocked, Backup is not Fresh, or the application asks for live information.

## Your daily check

1. Review the environment, Operations, and Backup cards.
2. Refresh the funding case inbox.
3. Look for these attention states:
   - Quarantined
   - Intake Hold
   - Information Required
   - Possible Match
   - Reversed
   - Partial
   - Blocked
   - Failed
4. Record the date, time, your name, and the result of the check.
5. If a state is unclear, leave the case unchanged and follow
   [If something fails](#if-something-fails).

## When you work a funding case

Complete the nine steps in order:

1. Upload package.
2. Review package health.
3. Compare claims and findings.
4. Add cited evidence and amendments.
5. Match the incoming provider credit.
6. Approve, reject, or request information.
7. Review exact payouts and fees.
8. Authorize and execute.
9. Reconcile and export evidence.

See [Funding-case guide](BROKERED_FUNDING_CASES.md) for the detailed procedure.

## If something fails

1. Do not retry authorization or execution.
2. Note the time, first eight characters of the case reference, screen name,
   status, and plain-language error.
3. Do not copy passwords, MFA codes, recovery codes, tokens, cookies, full
   account identifiers, balances, or package contents.
4. Leave the case unchanged.
5. Send the safe note to the named administrator through the approved support
   channel.

Use this template:

```text
Time:
Case reference (first 8 characters only):
Screen:
Status:
Plain-language error:
Action taken: Stopped without retrying
```
